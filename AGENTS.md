# Repository conventions

- Use master as the primary branch.
- Write commit messages, code comments, and documentation in English.
- Use Conventional Commits, such as feat(site): add testimonials carousel or fix(layout): align mobile footer.
- Keep user-facing content localized in Portuguese and English.
- Keep refs/, descarte/, artifacts/, node_modules/, dist/, and environment files out of Git.
- Use component-level Tailwind utilities and preserve reversible GSAP scroll behavior.
